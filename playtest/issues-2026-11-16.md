## 1. Questions are only in English, so the room switches language

Labels: `bug`

**Owner:** Lasse @lassenothelfer-IMS

The app is in German, French and Italian, but the questions come from the server, and the server only has 16 English ones. In a German room the popper picks from "What's a dealbreaker for you?", and every holder reads it in English. The same English text is used again when the chat is seeded with the questions after a match.

With only 16 questions, the popper also sees the same options again quickly: in a test room, two of the five options in round 2 had already been offered in round 1.

**Where**
- [convex/lib/questions.ts#L4-L21](https://github.com/lassenothelfer-IMS/popdate/blob/b261e76021263ea843a82bcbf74e333ef39797e3/mobile/convex/lib/questions.ts#L4-L21)

**Suggested fix**
- Give each question a key and its text in the four languages, either in the `questions` table or in the app's locale files keyed by question id. Show it in the reader's language.
- Write more questions, about 40, so a player doesn't see the same ones every night.

_Found in a browser run of the app (mock server, German) on 16 Nov 2026, and checked in the code on `main` at b261e76. Not yet checked on a phone._

## 2. Home has no quiet state: it says "0 Leute warten gerade"

Labels: `enhancement`

**Owner:** Lasse @lassenothelfer-IMS

When nobody is in line, Home shows "0 Leute warten gerade in Zürich". At launch that will be the most common sight outside game nights, and it tells people not to bother. The design has a quiet variant for this (X04, "Quiet in Zürich right now"), but the app doesn't have it.

**Where**
- [src/features/home/home-screen.tsx#L194-L204](https://github.com/lassenothelfer-IMS/popdate/blob/b261e76021263ea843a82bcbf74e333ef39797e3/mobile/src/features/home/home-screen.tsx#L194-L204)
- [src/i18n/locales/home.ts#L148-L149](https://github.com/lassenothelfer-IMS/popdate/blob/b261e76021263ea843a82bcbf74e333ef39797e3/mobile/src/i18n/locales/home.ts#L148-L149)
- Design: `design/DESIGN.md` section 8, "Empty queue", and `design/screens/game-velvet/X04Offline.html`

**Suggested fix**
- At 0 (or under a few), switch the line to the quiet variant and say when rooms usually open, for example "Most rooms open 20:00–22:00".
- Offer a reminder ("Tell me when a room is filling") that uses the push notifications.

_Found in the code on `main` at b261e76 on 16 Nov 2026. Not yet checked on a phone._

## 3. The pop has no sound

Labels: `enhancement`

**Owner:** Lasse @lassenothelfer-IMS

The design calls the pop "the one loud moment" and asks for two sounds: the pop and the match sting, on by default inside a live room, with one toggle in Settings and muted when the ringer switch is off. The app has haptics for the pop, but no sound files and no setting for them.

**Where**
- Design: `design/DESIGN.md` section 7, "Sound" (line 193)
- `expo-audio` is already a dependency (for voice messages)

**Suggested fix**
- Add a short pop and a match sting, played with `expo-audio` at the moment of the burst and the match.
- Add the "Pop and match sounds" toggle in Settings, and respect the ringer switch.

_Found in the code on `main` at b261e76 on 16 Nov 2026._

## 4. "0 Siege" in Rooms: dating as winning and losing

Labels: `enhancement`

**Owner:** Lasse @lassenothelfer-IMS

The Rooms tab sums up with "1 Raum gespielt, 0 Siege." It frames every room you didn't end up matched in as a loss, and a popper can never have a win at all, even after choosing a match.

**Where**
- [src/i18n/locales/rooms.ts#L36-L37](https://github.com/lassenothelfer-IMS/popdate/blob/b261e76021263ea843a82bcbf74e333ef39797e3/mobile/src/i18n/locales/rooms.ts#L36-L37) (and the same keys in English, French and Italian)

**Suggested fix**
- Count matches instead of wins, for poppers and holders alike: "1 Raum gespielt, 1 Match."

_Found in a browser run on 16 Nov 2026 and checked on `main` at b261e76._
